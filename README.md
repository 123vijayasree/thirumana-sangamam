# 💍 WeddingHub Tamil Nadu

A Figma design project for a one-stop marketplace to find and book wedding services across Tamil Nadu — from decoration and catering to photography and bridal makeup.

![Tamil wedding celebration](https://cdn.b12.io/client_media/tjfFcR7A/82bea58a-ad23-11f1-a588-0242ac110002-gc81HgPidPVgY-DNmWlaU_reZtojMS.jpg)

## ✨ Features

- Browse 17 wedding service categories
- Featured, highly-rated vendors with ratings, location and experience
- "Enquire Now" option on every vendor
- Compare vendors and prices in one place
- Easy booking with expert support
- Fully responsive layout
